# SQL Practice

## Purpose

This repository contains SQL practice exercises focused on refreshing database fundamentals and applying SQL concepts to business-oriented scenarios.

## Scenario

The examples are contextualized around working as a Technical Operations Analyst for a construction technology company, using SQL to answer questions involving employees, projects, and operations.

## Topics Covered

- SELECT statements
- Filtering with WHERE
- Sorting with ORDER BY
- DISTINCT values
- Aggregations with COUNT()
- GROUP BY and HAVING
- INNER JOIN
- LEFT JOIN

## Future Additions

- Advanced SQL queries
- Business analytics examples
- Reporting and data analysis projects
